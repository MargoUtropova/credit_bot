Это бот, который помогает фиксировать данные по кредитным картам и не пропускать платежи.

Что делает бот:
- Показывает данные по всем картам
- Позволяет выбрать карту, по которой нужны данные
- Показывает данные по карте, ее тарифам и условиям
- Показывает данные о следующем платеже по карте
- Уведомляет о предстоящем платеже
- Запоминает (записывает) данные через переписку и обновляет их в общей таблице

Ниже инструкция "для чайников" как установить себе этого бота.
--------------------------------------------------------------
#Создать папку проекта, перейти в нее в терминале
```
cd <название папки>
```
#создать папку гит
```
git init
```
#войти в IDE сразу в нужную папку и далее работать в ней
#создать виртуальное окружение:
```
python3 -m venv .venv -- MacOs, Linux
python -m venv .venv -- Windows Powershell
```
#активировать виртуальное окружение
```
source .venv/bin/activate  # Для MacOS и Linux
.venv\Scripts\activate  # Для Windows
```
далее клонируем проект с гита в рабочую папку
